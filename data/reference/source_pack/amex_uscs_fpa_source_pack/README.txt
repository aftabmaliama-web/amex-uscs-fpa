American Express U.S. Consumer Services FP&A Source Pack
Project: Annual Operating Plan, Rolling Forecast & Performance Management

This pack contains a source manifest and organized folder structure for the public Amex materials needed for the project.

NOTE: The source websites block direct binary downloading from this environment, so the PDFs are not embedded in this ZIP. Use source_manifest.csv to download each official Amex file into its matching folder.

Recommended use:
1. Download each source using source_manifest.csv.
2. Place it into the folder shown in target_folder.
3. Use 2024 materials to construct a 2025 AOP without hindsight leakage.
4. Use 2025 actual results to backtest the AOP.
5. Use Q1/Q2 2026 results for the rolling forecast and latest estimate.
